About Me

I build systems where code eventually has to move something, measure something, communicate with something — or fail in the real world.

My projects move between PCB design, embedded firmware, FPGA/digital design, robotics and edge intelligence, with one recurring obsession: understanding what happens below the abstraction layer.

From custom STM32 boards and autonomous robots to RISC-V cores, FreeRTOS applications and industrial control systems, I use each project as a way to explore how hardware, software and physical behavior meet.

That intersection is where I want to keep working.

Projects

32-bit RISC-V Processor (RV32I) – SystemVerilog Implementation

From raw machine code to a working processor. This RV32I core brings together instruction fetch, decoding, register operations, ALU execution, memory access and branching inside a complete single-cycle architecture written in SystemVerilog.

Review Project

Autonomous Sumo Robot – PCB Design & Embedded Programming

HAKUHO turns sensor data into movement in milliseconds — spotting opponents, detecting the ring edge and commanding both motors through a custom STM32-based control board built specifically for autonomous sumo combat.

Review Project

FusionCore-MX – Altium Designer

A playground for serious hardware design. FusionCore-MX brings STM32 processing, Ethernet, mixed-signal acquisition and motor control onto a dense multilayer PCB, with the focus pushed beyond connectivity into stack-up planning, PDN behavior, high-speed routing and EMI-aware layout.

Review Project

FPGA & VHDL Digital Systems

From RTL to a programmable system. This work explores arithmetic logic, FSMs and processor-style architectures in VHDL, then bridges hardware and software through a NIOS II soft-core running C on FPGA.

Review Project

ESP32 WiFi IoT Application for AWS Cloud Integration

From sensor data to the cloud. This ESP32 platform combines FreeRTOS multitasking, WiFi, MQTT and AWS IoT Core with an embedded web server, OTA updates and persistent storage to create a complete connected-device firmware architecture.

Review Project

Industrial PLC Supervision with HMI

From ladder logic to a moving production line. The project recreates an automated mixing, filling, capping and packaging process using RSLogix 500, RSLogix Emulate 500, RSLinx and an interactive RSView32 supervision interface.
